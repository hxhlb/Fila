Fila 0.6.8 completes its access to the graphics processor, so iOS features that draw with it cannot close the app.

- Fila already had graphics access for the terminal. iOS also draws app icons, Bold Text and the share sheet with the graphics processor, and a few of the pieces those need were missing. Fila now asks for the same list as the other OwnGoal apps.
- Every package is now checked for that access before it is published, so a build without it is not released.

Choose the RootHide or the rootless Debian package for a jailbroken device, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
