Fila 0.6.6 changes nothing you will see. It adds tests that keep archive names with non-English characters working.

- Fila's archive helper runs with no language settings of its own. New tests check that, even so, names such as "What’s New 中文.html" and link targets list correctly and survive being zipped or tarred and extracted again. Fila already handled these names; the tests make sure it keeps doing so.

Choose the RootHide or the rootless Debian package for a jailbroken device, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
