Fila 0.6.5 changes nothing you will see. It makes sure every package still opens on the oldest iOS Fila supports.

- Before a package is published, each part of it is now checked against iOS 15, the oldest version Fila supports. A package that would close the moment it opens on an older iPhone or iPad is no longer released.

Choose the RootHide or the rootless Debian package for a device running custom firmware, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
